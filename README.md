# Çay Bardağı Diplomatik Protokolü

> Resmi sınıflandırma: ince belli, sıcak, kırılgan ve aşırı ciddi.

Bu depo, dünyanın en küçük dışişleri krizini çözer: masada son yudum kime aittir.

Komşu bardak hak iddia eder. Kendi bardağın tabağı nota verir. Şeker küpü gözlemci olarak oturur, oy kullanamaz, sadece erir. Protokol bunu milisaniye değil, yudum cinsinden ölçer.

## Neden var

Çünkü birisi sordu: “bu kod ne işe yarıyor?” Cevap: hiçbir şeye, ama düzgün çalışıyor. Birleşmiş Bardaklar çay molasını erteledi, biz ertelemedik.

## Kurulum

Python 3 yeter. Bağımlılık yok. Çay opsiyonel, tavsiye edilir, depoya sığmaz.

```bash
python protokol.py
python protokol.py --tur 5 --sicaklik 78
```

Çıkış kodu `0` ise kriz kağıt üstünde çözülmüştür. Bardak yine de kırılabilir. Bu yazılım cam sigortası değildir.

## Protokol maddeleri

1. Bardak boş değilse konuşulur.
2. Bardak boşsa daha yüksek sesle konuşulur.
3. Tabak, bardağın gölgesidir ve gölge oy kullanamaz.
4. Son yudum paylaşılmaz, tutanak altına alınır.
5. Kimse “bir çay daha” demeden oturum kapanmaz. Biri illa der.

## Dosyalar

- `protokol.py` — çalışan kriz masası.
- `tutanak.ornek.txt` — örnek oturum.
- `.gizli/dipnot.txt` — arşiv notu. Merak eden kendi açar.
